# スカイライン・テクノロジーズ コーポレートサイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」の1ページ構成コーポレートサイトです。

> **注意:** 本サイトは架空の企業を題材としたサンプルです。会社名・代表者名・所在地・連絡先・実績数値・導入事例はすべてフィクションであり、実在の企業や団体とは関係ありません。

## 概要

| 項目 | 内容 |
| --- | --- |
| サイト種別 | 企業コーポレートサイト（シングルページ） |
| 構成ファイル | `index.html` 1ファイルのみ |
| 依存関係 | なし（CSS・JavaScript はファイル内にインライン記述） |
| ビルド | 不要 |

### セクション構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピー、CTAボタン、実績数値（スクロール時にカウントアップ） |
| サービス | クラウドネイティブ開発／データ基盤・分析／AIプロダクト開発 の3領域 |
| 強み | 4ステップの開発プロセスと、擬似ターミナル風のデプロイ設定表示 |
| 導入事例 | 架空3社のケーススタディ（改善指標つき） |
| 会社概要 | 設立・代表者・拠点・事業内容などの一覧表 |
| お問い合わせ | 連絡先情報と問い合わせフォーム（デモ動作） |

### 実装のポイント

- ダークテーマ＋グラデーションアクセントの配色
- `IntersectionObserver` によるスクロール連動フェードイン
- 900px / 640px のブレークポイントでレスポンシブ対応（モバイルはハンバーガーメニュー）
- `prefers-reduced-motion` 指定時はアニメーションを無効化

## ブラウザで開く手順

ビルドもサーバーも不要です。次のいずれかの方法で表示できます。

### 方法1: ファイルをダブルクリックする（最も簡単）

1. エクスプローラーで `company_site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリック →「プログラムから開く」から選択してください。

### 方法2: PowerShell から開く

```powershell
cd "C:\Users\naoki\OneDrive\デスクトップ\company_site"
Start-Process index.html
```

ブラウザを指定して開く場合:

```powershell
Start-Process msedge index.html    # Microsoft Edge
Start-Process chrome index.html    # Google Chrome
```

### 方法3: ローカルサーバーを起動する

`file://` ではなく `http://` で確認したい場合（キャッシュ挙動の確認など）は、簡易サーバーを使います。

```powershell
cd "C:\Users\naoki\OneDrive\デスクトップ\company_site"
python -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000/> を開きます。停止は `Ctrl + C` です。

Node.js 環境であれば次のコマンドでも同じことができます。

```powershell
npx serve .
```

## 動作確認済み環境

Chromium 系ブラウザ（Chrome / Edge）、Firefox、Safari の最新版を想定しています。`IntersectionObserver` と CSS カスタムプロパティを使用しているため、Internet Explorer では正しく表示されません。

## カスタマイズ

配色は `index.html` 冒頭の `:root` に定義した CSS カスタムプロパティで一括変更できます。

```css
:root{
  --bg:#0a0e1a;        /* 背景色 */
  --accent:#4cc9f0;    /* アクセントカラー */
  --accent-2:#5d7bff;  /* アクセントカラー（サブ） */
  --grad:linear-gradient(120deg,#4cc9f0,#5d7bff 55%,#a86bff);
}
```

## 既知の制限

- お問い合わせフォームは送信先を持たないデモです。送信ボタンを押すと完了メッセージが表示されるだけで、入力内容はどこにも送信されません。実運用するにはバックエンドの実装、または Formspree 等の外部フォームサービスとの接続が必要です。
- 掲載している画像はなく、事例サムネイルは CSS のグラデーションで描画しています。
